# 🌊 专题：大洋中脊与海底扩张

大洋中脊是全球最长的山脉，也是洋壳生成的“工厂”。

## 🌋 扩张机制可视化
在中脊轴部，岩浆上涌填补板块张裂的空间，冷凝形成新的玄武岩。

### 关键证据
1. **地磁条带**：洋脊两侧的地磁异常互为镜像，记录了地球磁场的周期性倒转。
2. **洋壳年龄**：离洋脊越远，岩石年龄越老（c = L / t）。
