# 🌊 大洋中脊：地球的生长边界

大洋中脊（Mid-Ocean Ridge）是贯穿全球洋底的巨型山脉系统，它是地球上最新洋壳诞生的地方。

### 1. 核心动力：海底扩张
根据海底扩张学说，地幔物质在中脊轴部涌出，冷凝形成新的玄武岩洋壳，并向两侧推移。
- **证据**：沉积物厚度随远离中脊而增加；岩石年龄随远离中脊而变老。

### 2. 深海热液喷口 (Black Smokers)
在中脊轴部，海水渗入裂缝被岩浆加热，携带大量矿物质喷出，形成漆黑的“烟囱”。
- **生物意义**：这里存在基于**化能合成**的独特生态系统，无需阳光，是研究生命起源的关键。

### 3. 地磁倒转条带
洋壳中的磁性矿物记录了形成时的地球磁场方向。
- **镜像对称**：中脊两侧的磁异常条带互为镜像，完美证实了地壳的持续扩张。
