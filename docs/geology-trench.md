# 🕳️ 专题：海沟与俯冲消亡

海沟是板块构造的“终点站”，高密度的洋壳板块在此重回地幔。

## 🏹 俯冲带动力模拟
当洋壳与陆壳碰撞，较重的洋壳俯冲向下，带入的水分会降低地幔熔点，引发火山喷发。

### 考察重点：马里亚纳海沟
* **深度**：约 11,000 米，压力是海表面的 1000 倍。
* **现象**：强烈的深源地震带（贝尼奥夫带）。
