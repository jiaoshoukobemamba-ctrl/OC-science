# 🕳️ 海沟：洋壳的终焉之地

海沟（Oceanic Trench）是海洋中最深的地方，也是大洋板块重回地幔的“消亡入口”。

### 1. 俯冲带机制 (Subduction)
当高密度的洋壳板块与较轻的大陆板块（或较年轻的洋壳）碰撞时，老洋壳会向下折叠并插进地幔。
- **马里亚纳海沟**：全球最深处（约 11,034 米），其压力是海平面的 1000 多倍。

### 2. 伴生地质现象
- **弧火山**：俯冲板片带入的水分降低了地幔熔点，引发岩浆上升，形成如日本群岛、安第斯山脉等火山弧。
- **深源地震**：俯冲带是全球地震最活跃、震级最高的区域（如贝尼奥夫带）。

### 3. 极深渊生态 (Hadal Zone)
尽管压力巨大、黑暗无光，海沟中仍生活着特化的钩虾、狮子鱼等生物，依靠上层掉落的“海洋雪”生存。
