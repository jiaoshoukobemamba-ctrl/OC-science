# 🧪 海洋化学：化学平衡与循环

本模块结合全球碳循环及海水组成特性，探讨海洋中的关键化学过程。

## 1. 海洋碳泵过程
海洋通过四个关键泵过程调节大气 CO₂：
1. **溶解泵**：大气 CO₂ 溶解于表层海水，通过温盐环流下沉至深海。
2. **生物泵**：浮游植物通过光合作用将无机碳转化为有机碳，并随颗粒物下沉。
3. **碳酸盐泵**：海洋生物形成碳酸钙 (CaCO₃) 壳体并沉降。
4. **微生物碳泵 (MCP)**：微生物将易降解有机碳转化为长期封存的惰性溶解有机碳。

## 2. 海洋碳酸盐体系与酸化
大气 CO₂ 增多会导致海水 pH 下降（酸化）：
* **平衡反应**：CO₂ + H₂O ⇌ H₂CO₃ ⇌ H⁺ + HCO₃⁻ ⇌ 2H⁺ + CO₃²⁻
* **后果**：H⁺ 增多导致碳酸根 (CO₃²⁻) 减少，珊瑚等钙化生物难以合成 CaCO₃。

## 3. 海洋组分与盐度
* **恒比定律**：在开阔大洋中，海水主要组分的浓度比例基本恒定。但在近岸（河流径流）、冰冻/融化区或热液口附近会发生偏离。
* **盐度差异**：相同纬度下，大西洋因蒸发较强且通过地峡输送水汽，其表层盐度高于太平洋。

## 4. 溶解氧剖面 (DO Profile)
* **特征**：表层受大气交换和光合作用影响呈饱和态；随深度增加进入“氧极小值层”（生物呼吸与有机物分解耗氧）；深层受富氧冷水团注入影响氧含量回升。
