# 🌋 海洋地质与板块构造

研究海底地貌及其背后的地质动力。

## 1. 板块边界类型
海洋地质的核心在于板块的诞生与消亡。

- **[大洋中脊 (Mid-Ocean Ridge)](geology-ridge.md)**：洋壳的新生之地，伴随强烈的地热活动。
- **[海沟与俯冲带 (Trench)](geology-trench.md)**：如马里亚纳海沟，洋壳在这里重回地幔。



---

## 2. 沉积物分类
1. **陆源沉积**：由河流带入海洋。
2. **生物源沉积**：由浮游生物遗骸（软泥）组成。
