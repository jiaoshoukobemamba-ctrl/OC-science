# 海洋地质学 (Marine Geology)

研究地球海洋底部的构造、起源、演化以及沉积物的特征。

## 1. 海底扩张与板块构造
* **大洋中脊 (Mid-Ocean Ridge)**：地幔物质上涌，新地壳形成的地方。
* **俯冲带与海沟**：大洋板块消亡进入地幔的区域。
* **威尔逊循环**：大洋从产生、发育、消亡到关闭的完整演化周期。

## 2. 海底地貌单元
* **大陆边缘**：
    * 被动大陆边缘（如大西洋型）：陆架、陆坡、陆基。
    * 主动大陆边缘（如太平洋型）：伴随海沟和火山弧。
* **深海盆地**：深海平原、海丘、海山。

## 3. 海洋沉积学
* **按来源分类**：
    * 陆源沉积（河流、冰川、风力带入）。
    * 生物源沉积（钙质软泥、硅质软泥）。
    * 深海红粘土。
* **碳酸盐补偿深度 (CCD)**：碳酸盐供给与溶解达到平衡的深度。

## 4. 古海洋学
* **稳定同位素应用**：利用 $\delta^{18}O$ 还原古代海水的温度变化。
* **深海钻探 (IODP)**：获取沉积物柱芯以研究数百万年来的气候变迁。
