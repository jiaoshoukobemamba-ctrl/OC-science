# 🌋 海洋地质：地壳的史诗

> **交互指引**：跟随这份考察指南，通过板块的扩张与消亡，观察地球表面的演变。

### 🚢 考察记录：板块边界实验室

> [!TIP]
> **坐标：大洋中脊 (Mid-Ocean Ridge)**
> **观察记录**：这里是地球的“生长点”，炽热岩浆涌出形成新洋壳。
> **科学发现**：离脊轴越远，玄武岩的年龄越老，沉积层越厚。



> [!ATTENTION]
> **坐标：马里亚纳海沟 (Subduction Zone)**
> **观察记录**：古老的洋壳在这里折叠、俯冲，重新进入地幔。
> **风险提示**：此区域伴随剧烈的深源地震与弧火山活动。

### 🌏 板块运动对比表
| 边界类型 | 动力过程 | 典型地貌特征 |
| :--- | :--- | :--- |
| **离散边界** | 扩张 | 大洋中脊、裂谷 |
| **汇聚边界** | 俯冲/碰撞 | 海沟、岛弧、山脉 |
| **转换边界** | 剪切错动 | 走滑断层 (如圣安德烈亚斯) |

> [!NOTE]
> **地磁条带**：海底扩张的“录音带”。岩石记录了地球磁场极性的周期性倒转，在洋脊两侧形成对称的条纹。这是大陆漂移学说最强有力的证据之一。
