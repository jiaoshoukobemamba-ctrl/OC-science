# 🧪 海洋生化与碳循环

海洋是一个巨大的化学反应器，通过物质循环调节着全球气候的稳态。

## 1. 海洋碳泵机制 (Carbon Pump)
海洋通过生物和物理过程将大气中的 $CO_2$ 转移并封存至深海。

### 海洋酸化化学平衡
当大气中的 $CO_2$ 溶解于海水，会建立一系列动态平衡。如果平衡向右移动，海水酸度增加：

1. **溶解与水合**：
   $$CO_2(g) + H_2O \rightleftharpoons H_2CO_3$$
2. **一级电离**：
   $$H_2CO_3 \rightleftharpoons H^+ + HCO_3^-$$
3. **二级电离**：
   $$HCO_3^- \rightleftharpoons H^+ + CO_3^{2-}$$

> [!WARNING]
> **生存威胁**：由于 $H^+$ 浓度升高，$\text{pH}$ 值下降，会导致海水中碳酸根 ($CO_3^{2-}$) 减少，使得珊瑚、贝类难以合成碳酸钙 ($CaCO_3$) 外壳。

## 2. 营养盐与生产力
海洋生物的生长依赖于特定的营养比例。

* **红场比 (Redfield Ratio)**：
    浮游植物组织中碳、氮、磷的标准比例为：
    $$C:N:P = 106:16:1$$
* **限制因素**：在不同海域，生产力往往受限于氮 ($N$)、磷 ($P$) 或铁 ($Fe$) 的含量。

## 3. 生物地球化学循环
* **溶解氧 (DO)**：随深度增加先减少后增加（氧极小值层）。
* **生物泵**：有机颗粒物（海洋雪）下沉过程中的碳封存作用。
