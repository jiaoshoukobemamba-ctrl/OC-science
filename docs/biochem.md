# 海洋生物地球化学 (Marine Biogeochemistry)

研究海洋中化学元素及其同位素的分布、存在形态以及在生物圈、岩石圈和大气圈之间的循环。

## 1. 海水化学组成
* **常量元素**：符合恒定比例定则 (Marcet's Principle)。
* **营养盐**：氮 (N)、磷 (P)、硅 (Si) 是浮游植物生长的限制因素。
* **微量元素**：如铁 (Fe)，在某些海域（HNLC）限制了生产力。

## 2. 海洋碳循环 (核心重点)
* **无机碳系统**：$CO_2$、$HCO_3^-$、$CO_3^{2-}$ 之间的平衡。
* **海洋酸化**：由于大气 $CO_2$ 增加导致海水 pH 值下降，影响钙化生物。
* **生物泵 (Biological Pump)**：光合作用将无机碳转化为有机碳并向深海输送的过程。

## 3. 溶解氧与氧化还原
* **氧最小层 (OMZ)**：由于生物降解耗氧形成的低氧区。
* **表观耗氧量 (AOU)**：衡量海水自离开表层以来生物降解程度的指标。

## 4. 颗粒物与沉积
* **颗粒有机碳 (POC)** 和 **颗粒无机碳 (PIC)**。
* **清除作用 (Scavenging)**：重金属等物质吸附在颗粒物表面并沉降。
