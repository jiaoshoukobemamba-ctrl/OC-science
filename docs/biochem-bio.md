# 🐟 海洋生物：数字标本馆

探索从微观藻类到深海巨兽的生态分布。

## 🌿 生产者：浮游植物
* **基础生产力**：海洋中 90% 以上的初级生产由浮游植物完成。
* [cite_start]**Redfield Ratio**：C:N:P = 106:16:1 [cite: 8]。

## 🐙 消费者与分解者
* **食物网**：从磷虾到顶级掠食者的能量流。
* **海洋雪**：上层生物碎屑下沉，为深海生物提供能量。

## 💎 生态系统
* **珊瑚礁**：高多样性的海洋雨林。
* **热液口**：基于化能合成的极端生命形态。
