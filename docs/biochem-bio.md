# 🐟 海洋生物：生命的多样性

海洋生命从表层跨越到万米深渊，构成了地球上最复杂的生态系统。

## 1. 浮游生物 (Plankton)
* **浮游植物**：如硅藻、甲藻。它们是海洋生产力的基石。
* **浮游动物**：如磷虾、桡足类。它们将能量传递给更高级的消费者。

## 2. 海洋生态系统
* **珊瑚礁**：高生产力的“海洋热带雨林”。
* **深海热液区**：完全脱离阳光，依靠化能合成（如硫化氢氧化）支撑的独特性命链。

## 3. 生源要素分析
* **Redfield Ratio**：C:N:P = 106:16:1。
* **应用**：结合**表观耗氧量 (AOU)**，我们可以推算出生物活动导致的生源要素（如氮、磷）浓度变化。
